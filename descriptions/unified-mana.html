One unified mana pool for every supported magic mod, displayed on a single vanilla-style HUD bar!

Unified Mana replaces separate personal mana pools with one shared system: Unified Mana Points (UMP). Spells and tools from any supported mod draw from the same pool, regeneration fills it seamlessly, and native HUD bars are automatically hidden when a bridge is active.

Available for Minecraft 1.21.1 (NeoForge), 1.20.1 (Forge) and 26.1.2 (NeoForge). Pick the file for your version in the Files tab; the lists below show which mods each version supports.

⚠️ Early releases: 1.21.1 is at v0.10.0; the 1.20.1 and 26.1.2 builds start at v0.0.1. All bridges pass automated tests against the real mods, but long play sessions are still being collected, so occasional bugs may occur. More bridges are in development!

🗂️ Each version at a glance

  • 1.21.1 (NeoForge) — needs NeoForge 21.1.265+ and Java 21. Seven bridges: Ars Nouveau, Iron's Spells, Mahou Tsukai, Arcanum Unbound, Confluence, Dragon Survival and Botania Revived.
  • 1.20.1 (Forge) — needs Forge 47.4.10+ and Java 17. Five bridges: Mana and Artifice, Iron's Spells, Ars Nouveau, Mahou Tsukai and Arcanum Unbound. Not yet: Confluence, Botania, Dragon Survival.
  • 26.1.2 (NeoForge) — needs NeoForge 26.1.2 and Java 25. Two bridges: Ars Magica: Legacy and Mahou Tsukai. Ars Nouveau and Iron's Spells have no 26.1.2 build yet; their bridges follow when they appear.

Install the mods you use; if none are present, Unified Mana stays safely idle. Unsupported mod versions are left untouched with a log warning.

  • One Shared Pool (UMP): Cast an Ars Nouveau glyph spell, an Iron's Spells incantation, a Mana and Artifice spell, an Ars Magica ability, a Confluence magic weapon, an Arcanum sigil, or Mahou Tsukai magic — all draw directly from your unified UMP pool.
  • Vanilla-Style Split HUD: A clean mana bar aligned with the vanilla XP strip, split in the middle so your XP level number remains visible. Includes a left-to-right fill animation with an edge spark, low-mana pulse, and full-pool flash.
  • Compact Numeric Window: Displays current / max in a framed window next to the bar (configurable to LEFT or RIGHT side).
  • Smart Bridge Management: Native bars are hidden only when an active bridge is detected. Unsupported mods keep their default resources untouched.
  • No Double Accounting: Costs and regeneration rates are calculated once from the shared pool.
  • Server-Authoritative Sync: Server manages balance policy and syncs data to clients for seamless multiplayer consistency.
  • Source Diagnostics: Run /unifiedmana sources to inspect active bridges and see how much capacity each mod contributes to your pool.

  • Botania Spending Rules: Botania adds no pool capacity, as it lacks a personal mana pool. Its tools and rings spend UMP after your mana tablets/rings at 2.67 Botania mana per UMP. The pool never recharges Botania items, and the world mana network remains untouched.
  • Global Cap: Pool total is capped at 5,000 UMP by default (global_mana_cap). Because capacity is shared, individual mods may display higher native mana than their own default cap.

📌 Requirements

  • The Minecraft version and loader of the file you download (see the lists above), on Client & Server.
  • Mods that need helpers: Botania Revived and Ars Magica: Legacy need Patchouli; Confluence, Mana and Artifice and Arcanum Unbound need Curios API; Confluence, Mana and Artifice, Dragon Survival and Ars Magica: Legacy need GeckoLib. Unified Mana itself needs nothing besides the loader.

📚 Same Author Mods & Ecosystem

  • Spell's Atlas — Unified settings hub, stat integration, and spell history logging.
  • Quintessence: Elemental Spellcraft & Runes — Native integration with pentagram spells and mana wells.
  • Player System — Shared mana pool compatibility for System skill consumption.
  • Artificer's Almanac — Power modular staffs and Manalite cells through unified UMP.

  • Flexible Configs:
    • unifiedmana-common.toml: Configure global caps, conversion rates, per-bridge toggles (<mod>_enabled), Botania rate, regeneration switch, and sync thresholds.
    • unifiedmana-client.toml: Customize HUD visibility, numbers, side offset (LEFT/RIGHT), and native bar hiding.
  • Developer API: Includes a server API (UnifiedManaAPI, ManaSourceProvider) allowing addon authors to register custom mana sources and spend UMP.

  • Regeneration Toggle: Disabling regeneration in the config also blocks mana from potions and refunds, as they share the same internal path.
  • Pinned Versions: Supported mod versions are pinned; updating magic mods may require a matching Unified Mana build.
  • Botania with Ars Nouveau: With Ars Nouveau installed, Botania's own Ars bridge already spends from the pool, so the direct Botania source stays idle (botania_direct_source_with_ars forces both).
  • Confluence Conversion: If Confluence's own Ars Nouveau / Iron's Spells mana conversion is turned on, the Confluence bridge stays idle so spells are not charged twice. Every Confluence player has at least 20 UMP of capacity (one star).
  • Native Overlays: The own mana displays of Arcanum Unbound, Mana and Artifice and Ars Magica: Legacy stay on screen (they show the shared value in that mod's points); Dragon Survival's mana icons show the dragon's share, at most its own maximum.
  • Dragon Survival: Experience-as-mana, reserved mana and the Source of Magic stay native.
