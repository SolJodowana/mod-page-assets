This is a library mod. It adds no blocks, items or mobs by itself. Install it only if another Folkforge mod requires it.

Folkforge - Library is the shared foundation for my series of themed village mods. On its own it does nothing visible in the game; the themed mods build their villages on top of it.

Supports Minecraft 26.1.2 (NeoForge) and Minecraft 1.20.1 (Forge).

  • Themes: A village style defined once and reused.
  • Villages in world data: Villages are stored in the world.
  • Residents: Professions and trades loaded from data files.
  • Reputation: Player reputation per village.
  • Families: Children and breeding.
  • Guards: Villages can defend themselves.
  • Starter template: A theme template and documentation, written so a new themed village can be built quickly.

📌 Requirements

  • NeoForge: Minecraft 26.1.2 + NeoForge 26.1.2 (Java 25 required)
  • Forge: Minecraft 1.20.1 + Forge 47.4.10+ (Java 17 required)

📚 Mods That Use It

  • Goblin Villages — Walled goblin villages with tunnels, a bounty board and five jobs.
  • Elven Villages — Elven settlements high in giant trees.
  • Blind Folks — Underground chambers of a people who hear you instead of seeing you.

  • This library is made for my own mod series. It is not meant to be a general-purpose public API yet, and I do not promise support for third-party mods.
