One unified mana pool for every supported magic mod, displayed on a single vanilla-style HUD bar!

Unified Mana replaces separate personal mana pools with one shared system: Unified Mana Points (UMP). Spells and tools from any supported mod draw from the same pool, regeneration fills it seamlessly, and native HUD bars are automatically hidden when a bridge is active.

Supports Minecraft 1.21.1 (NeoForge).

⚠️ Early Release Note (v0.9.0): Features the shared UMP pool, split HUD, and bridges for Ars Nouveau, Iron's Spells 'n Spellbooks, Mahou Tsukai, Botania Revived, Confluence: Otherworld, and Arcanum Unbound.

  • One Shared Pool (UMP): Cast an Ars Nouveau glyph spell, an Iron's Spells incantation, a Confluence magic weapon, an Arcanum sigil, or Mahou Tsukai magic — all draw directly from your unified UMP pool.
  • Vanilla-Style Split HUD: A clean mana bar aligned with the vanilla XP strip, split in the middle so your XP level number remains visible. Includes a left-to-right fill animation with an edge spark, low-mana pulse, and full-pool flash.
  • Compact Numeric Window: Displays current / max in a framed window next to the bar (configurable to LEFT or RIGHT side).
  • Smart Bridge Management: Native bars are hidden only when an active bridge is detected. Unsupported mods keep their default resources untouched.
  • No Double Accounting: Costs and regeneration rates are calculated once from the shared pool.
  • Server-Authoritative Sync: Server manages balance policy and syncs data to clients for seamless multiplayer consistency.
  • Source Diagnostics: Run /unifiedmana sources to inspect active bridges and see how much capacity each mod contributes to your pool.

  • Dynamic Capacity: Each supported mod contributes its native maximum to your UMP total via configurable conversion rates:
    • Ars Nouveau: 1.5 UMP per native point
    • Iron's Spells 'n Spellbooks: 2.0 UMP per native point
    • Mahou Tsukai: 1.0 UMP per native point
    • Confluence: Otherworld: 1.0 UMP per native point (20 mana per star)
    • Arcanum Unbound: 1.0 UMP per native point
  • Botania Spending Rules: Botania adds no pool capacity, as it lacks a personal mana pool. Its tools and rings spend UMP after your mana tablets/rings at 2.67 Botania mana per UMP. The pool never recharges Botania items, and the world mana network remains untouched.
  • Global Cap: Pool total is capped at 5,000 UMP by default (global_mana_cap). Because capacity is shared, individual mods may display higher native mana than their own default cap.

🔮 Planned Mod Bridges

  • Dragon Survival (pending confirmation of mana resource mechanics)

  • Flexible Configs:
    • unifiedmana-common.toml: Configure global caps, conversion rates, per-bridge toggles, Botania rate, regeneration switch, and sync thresholds.
    • unifiedmana-client.toml: Customize HUD visibility, numbers, side offset (LEFT/RIGHT), and native bar hiding.
  • Developer API: Includes a server API (UnifiedManaAPI, ManaSourceProvider) allowing addon authors to register custom mana sources and spend UMP.

  • Regeneration Toggle: Disabling regeneration in the config also blocks mana from potions and refunds, as they share the same internal path.
  • Pinned Versions: Supported mod versions are pinned; updating magic mods may require a matching Unified Mana build.
  • Botania with Ars Nouveau: With Ars Nouveau installed, Botania's own Ars bridge already spends from the pool, so the direct Botania source stays idle (botania_direct_source_with_ars forces both).
  • Confluence Conversion: If Confluence's own Ars Nouveau / Iron's Spells mana conversion is turned on, the Confluence bridge stays idle so spells are not charged twice. Every Confluence player has at least 20 UMP of capacity (one star).
  • Arcanum Overlay: Arcanum's own mana overlay stays on screen (it also displays your sigil and instability) and shows the shared value in Arcanum points.
