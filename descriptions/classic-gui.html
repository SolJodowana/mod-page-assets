A lightweight client-side addon for NeoOrigins that replaces its parchment-style interfaces with the compact, nostalgic window classic Origins players remember—displaying one origin at a time in a crisp, vanilla Minecraft GUI style.

Supports Minecraft 1.21.1 and 26.1.x – 26.3 (NeoForge) (Client-side only).

  • Classic Origin & Class Chooser: Replaces the selection screen with a 176-pixel-wide vanilla-style window featuring the origin's icon, title, impact dots, description, and scrollable power list. Flip between origins using the navigation buttons or your Left / Right arrow keys.
  • Classic Origin Info Screen (O): Displays your active origin and layers in the same clean, read-only window (one page per layer).
  • Full Search & Navigation Preserved: The search bar and sort toggle sit neatly above the window, while Random and Back buttons sit cleanly below it.

Everything else in NeoOrigins remains completely untouched—powers, resource HUD bars, the in-game origin creator, and the HUD editor continue to work exactly as before.

Customize which screens use the classic look in config/neoorigins_classic_gui-client.toml (or via Mods → NeoOrigins Classic GUI → Config):

  • classic_picker (default: true) — Enables the classic window when choosing an origin or class.
  • classic_info (default: true) — Enables the classic window for the Origin Info screen.

Set either option to false at any time to revert that screen back to NeoOrigins' default parchment UI.

  • Simplified Info Screen: By design, the classic info screen omits the Other Powers tab, evolution paths, and editor shortcuts. Set classic_info = false if you prefer access to those features.
  • Resource Pack Behavior: Resource packs will restyle the buttons and scrollbar automatically, while the main window panel renders in classic vanilla colors.
  • Safe Fail-Safe: Because this addon hooks into NeoOrigins' screen internals, if a future NeoOrigins update alters them, the addon safely disables itself and falls back to the default NeoOrigins screens without crashing your game until an update is released.
