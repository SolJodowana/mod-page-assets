Equivalent exchange for your Arcane Storage Network! Sacrifice excess items to learn them, bank their Equivalence Value (EV), and materialize any known item right inside your existing network window.

Supports Minecraft 26.1.2 (NeoForge).

⚠️ Work in Progress: This addon is under active development—UI layouts, icons, and default value tables may change in future updates. Always back up your worlds before updating!

  1. Craft an Equivalence Matrix and right-click your Core Pylon to unlock the Transmutation tab in every Arcane Interface.
  2. Place an item on your cursor and press Sacrifice. The first sacrifice learns the item (consuming one copy), while every subsequent copy adds its Equivalence Value (EV) to the network's shared reserve.
  3. Click any known item in the grid to materialize one copy, or Shift + Click for a full stack.

  • Pure Bookkeeping, No Exploits: Items are bought and sold using the exact same value table—no sequence of conversions can generate free value.
  • Plain Items Only: Items with extra data (durability damage, enchantments, custom names, or container contents) are automatically rejected to prevent duplication or accidental data loss.
  • Shared Network Pool: Learned items and EV reserves belong to the network, not individual players, following your Arcane Storage Network access permissions and matching all three visual themes.
  • Inventory-Safe & Server-Validated: If your inventory fills up mid-craft, you are charged only for what actually fits. All transactions and permissions are verified server-side.
  • Non-Destructive Toggle: Disabling the addon in the config safely preserves all stored knowledge and EV reserves.

🧩 Optional Mod Integrations

  • Recipe Viewers: Full recipe support for JEI and EMI.

  • Datapack-Driven Values: Define custom EV tables and item exclusions via lightweight JSON files. Built-in values cover vanilla basics (stone, logs, ores, ingots, redstone, gems, netherite scrap, and core mob drops), while unlisted modded items are safely refused by default.
  • Granular Configs: Toggle the addon or matrix independently, disable learning, adjust whether learning consumes an item, cap batch sizes, enforce blacklists, or set fallback default values.

  • Does it work standalone? No, it requires Arcane Storage Network (the main mod works completely fine without this addon).
  • Why is my modded item refused? Unlisted items have no EV by default to prevent balance issues. Assign values via datapack or enable default fallback values in the config.
  • Can I trade a stack of dirt for diamonds? No—dirt is worth 1 EV, while a single diamond costs 1,024 EV.
